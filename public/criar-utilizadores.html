Criar utilizadores

Os utilizadores são criados no Supabase Auth. O profile (nome, papel, nível de aprovação) é criado automaticamente por trigger e depois ajustado com o SQL abaixo.

1 · Criar as contas no Auth

Vai a Authentication → Users → Add user → Create new user e cria as três contas. Marca Auto Confirm User para não ser preciso confirmar por email.
NomeEmailPapelAprovação
Felipefelipe@lpxprivate.ptadminNível 2 · cria mapas
Rodrigorodrigo@lpxprivate.ptgestorNível 1
Thiagothiago@lpxprivate.ptgestorNível 1
Se o domínio de email não for @lpxprivate.pt, altera-o nesta página e no SQL abaixo antes de correr. Define palavras-passe fortes e distintas; podem ser alteradas depois em Authentication → Users.

2 · Definir papéis e níveis de aprovação

Cola no SQL Editor do Supabase, depois de as três contas existirem. 
-- Garante que existe um profile para cada utilizador do Auth
INSERT INTO profiles (id, nome, email, role)
SELECT u.id,
       initcap(split_part(u.email, '@', 1)),
       u.email,
       'viewer'
FROM auth.users u
ON CONFLICT (id) DO NOTHING;

-- Felipe — administrador, aprovador de nível 2, pode criar mapas de pagamento
UPDATE profiles
   SET nome = 'Felipe', role = 'admin',
       approval_level = 2, can_create_mapas = true
 WHERE email = 'felipe@lpxprivate.pt';

-- Rodrigo — gestor, aprovador de nível 1
UPDATE profiles
   SET nome = 'Rodrigo', role = 'gestor',
       approval_level = 1, can_create_mapas = true
 WHERE email = 'rodrigo@lpxprivate.pt';

-- Thiago — gestor, aprovador de nível 1
UPDATE profiles
   SET nome = 'Thiago', role = 'gestor',
       approval_level = 1, can_create_mapas = true
 WHERE email = 'thiago@lpxprivate.pt';

-- Conferir o resultado
SELECT nome, email, role, approval_level, can_create_mapas
  FROM profiles ORDER BY role, nome;

3 · Papéis disponíveis

PapelO que vê / pode fazer
adminTudo, incluindo o separador Utilizadores
gestorTudo exceto gestão de utilizadores; pode importar e editar
viewerSó leitura; não vê o separador Importar

approval_level: 0 = não aprova · 1 = 1.ª aprovação de mapas · 2 = 2.ª aprovação (fecha o mapa).
